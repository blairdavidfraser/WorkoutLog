# Workout Log
#
# Format: 
#   - Any line starting with # is textual content, and not data.
#   - Each entry is a block of text with no newlines. 
#   - The first line gives the date in YYYY-MM-DD format, followed by ':', followed by the type of entry.
#   - All subsequent lines take the form: "<Tag>: <Value> -- <Comment>".
#   - Tag/Value lines can be separated by a newline or by the '|' character. Consider a '|' to be the same as a newline.
#   - The value of <Tag> is the string up from the line start to before the ':', trimmed on both ends of any whitespace.
#   - The value of <Value> is the string from after the ':' to before the '--' trimmed on both ends of any whitespace.
#   - The value of the <Comment> is the string from after the '--' to the end of the line, or before the next '|', trimmed of any whitespace.
#
# While the tags are freeform and can take any value, there are certain common tags that will appear repeatedly under each log entry type and are described here.
#
# Global Tags
# These tags could appear on any entry type.
#   - "Notes" which is freeform text giving additional context to the entry.
#   - "Pain" which is a number from 1-5 with 5 being most painful.
#   - "RPE" which is a number from 1-10 representing perceived effort of a workout.
#   - "Watts" which is a number representing measured watts on a workout, where available.
# 
# Log Type = Daily
# This represents just daily data about the body not associated with any workout. All tags are optional, but would generally include:
#   - "Weight" which is a number representing body weight in pounds.
#   - "Waist" which is a number representing waist circumference in inches.
#   - "RHR" which is a number representing resting heart rate in bpm.
#   - "HRV" which is a number representing heart rate variablility in ms.
#   - "Sleep" which is a duration in HH:MM:SS representing the duration of sleep the previous night.
#   - "Energy" which is a number from 1 to 5 representing perceived energy level in AM.
#   - "Pain" which is a number from 1 to 5 representing any perceived pain in AM.
#   - "Illness" which is freeform describing any illness on that day.
# For example:
#   2025-11-01: Daily
#   Weight: 190 | Waist: 35.5 | RHR: 44 | HRV: 55
#   Sleep: 6:00:00
#   Energy: 3
#   Pain: 3 -- back tired but not sore
#
# Global Workout Tags
# These tags could appear on any workout type.
#   - "RPE" which is a number from 1 to 10 representing the perceived effort of the workout.
#   - "Avg HR" which is a number representing the average heart rate in bpm for the workout.
#   - "Max HR" which is a number representing the maximum heart rate in bpm for the workout.
#   - "Duration" which is a duration in HH:MM:SS representing the duration of the workout.
#   - "Details" which is a freeform field giving additional data describing the workout.  For example: a list of wattage per interval, or pace per interval.
#
# Log Type = Run | Row | Erg | Cycle | Swim 
# This represents a workout of the given modality. Erg means dry-land rowing on a rowing machine while Row means on-water rowing.
#   - "RPE" is mandatory on a workout of these types.
#   - "Duration" is mandatory on a workout of these types.
#   - "Distance" which is a distance in kilometers is mandatory on a workout of these types.
# For example:
#   2026-04-18: Run
#   RPE: 5 | Distance: 11.61 | Duration: 1:04:12 
#   Avg HR: 146 | Max HR: 167
#   Pain: 2 -- Niggles in right foot
#   Notes: Higher HR than Z2, but that’s because I’ve not been focusing on running and am out of run-shape. Perceived effort was low.
# For example:
#   2026-04-18: Rowing
#   RPE: 5 | Distance: 11.61 | Duration: 1:04:12 
#   Avg HR: 146 | Max HR: 167
#   Pain: 2 -- Niggles in right elbow
#   Notes: Easy technical row.
#
# Log Type = Strength
Weight: 20 |", meaning 3 sets of 5 reps at 20 pounds.
#   - "Focus" is a string representing the workout type. For example: Abs, Force Production, Upper Body
#   - "RPE" is mandatory on a strength workout.
#   - Other tags include, but are not limited to: 
#     - "Cable pallof press"
#     - "Bench press"
#     - "Leg press"
#     - "Single leg press"
#     - "Dumbbell shoulder press"
#     - "Glute bridge machine"
#     - "Assisted pull-up"
#     - "Chest supported row"
#     - "Back extension"
#
# Log Type = Nutrition
# This represents a log of what was eaten during the day. Tags represent the name of meals or snacks and values are what was eaten.
#
# Log Type = Measurements
# This represents a log of body measurements. Tags are body measurements and the value is the measurement in inches.
#
# Log Type = Data
# This represents auxiliary measurements. For example, results of a DEXA scan.
#
# Shorthand:
# These are non-standard formats in which some assumptions are made
#  - "2025-11-05: Cycle Commute | Duration: 50:00" is shorthand for a cycle workout of 50:00 at RPE 3.
#  - "2025-11-04: Yoga | Duration: 30:00" is shorthand for a yoga workout of 30:00 at RPE 1.
